Which addon is slowing you down?

Paste your addon links and get a straight answer: how fast each one answers, whether its catalogs, sources and subtitles actually work, and whether its key or setup has a problem. Then what to do about it.

One per line. Links ending in manifest.json or starting with stremio:// both work.

The check runs in your browser and talks only to the addons you paste. Your links, and any keys inside them, are never sent to MKCinema, saved, or put in this page’s address. The copied report leaves links out.

What it checks

  • Can it be reached? Down, moved, refusing requests, or blocking web pages (a browser can’t test those, and the tool says so instead of guessing).
  • Speed. How long the manifest, a catalog, sources and subtitles take, tested with famous titles like Inception and Breaking Bad. Slow addons are asked twice, to see if only the first lookup is slow.
  • Key and setup problems. Addons that answer with “invalid key”, “expired” or “please configure” instead of sources, or that say they still need to be set up.
  • Heavy answers. Hundreds of sources per title or huge catalogs that make phones and TVs crawl.
  • Your whole setup. Paste all your links to find the same addon installed twice, too many source addons, several addons on one overloaded server, and the single slowest addon everything waits for.
Results can change from hour to hour as addon servers get busy. A slow result once is normal; slow every time is the addon.

Built into MKCinema

In the app, open Addons › Check my addons. It checks every addon you have at once, shows a result on each one, and fixes things in one press: turn off the slow one, move it down, or keep one copy of a duplicate. MKCinema is free forever, with no ads.

Questions, answered.

Is my addon link safe to paste here?

Yes. The page has no server part: the check runs in your browser and only contacts the addon’s own server, the same way your player does. Nothing is stored or sent to MKCinema.

Why does it say “Can’t test here”?

Some addon servers only answer apps, not web pages (they send no CORS permission). A browser is not allowed to read their answers, so the tool can’t judge them. That is not the same as broken: native apps can still use them.

It says my key has a problem. What now?

Open the addon’s setup page, paste your current key from your service’s account page, and install the new link it gives you. Then remove the old link from your player.

Does it work with any player?

It checks the addon itself, so the results apply whichever app you use it in.

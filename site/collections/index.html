MKCinema › Collection maker

Free tool

Make a collection for Home.

Give it a name, a cover picture and a few rows of films and shows. MKCinema shows it as a folder on Home, with its own cover. Share it with a code or a link to the file.

Any picture link that starts with https. Wide pictures look best.
In MKCinema, open Settings › Home › Add a shared folder or collection and paste the code. Or save the file, put it on GitHub or any https site, and paste its link there.

How it works

  • Rows of titles. Search for films and shows by name and add them to a row. A collection can have up to 20 rows of 100 titles.
  • No addon needed to browse. The rows show posters and open title pages straight away. Playing still uses your own sources.
  • Private. Everything happens in your browser. Searches go to the public Cinemeta catalog, and nothing is sent to us.
  • Edit it later. In the app, open the folder and press Edit to change the name, cover or description.
A collection holds titles and pictures only. It never holds streams or links to them.

The file format

A plain JSON file, so other tools can make collections too:

{ "mkcinema": "collection", "v": 1, "name": "Heist night",
  "cover": "https://…/cover.jpg", "description": "…",
  "rows": [ { "name": "Classics", "titles": ["tt0113277", { "id": "tt0240772", "type": "movie" }] } ] }

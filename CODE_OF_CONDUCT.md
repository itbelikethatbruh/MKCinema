# Code of conduct

MKCinema is a friendly place to build something good together.

- Be respectful and assume good intent.
- No harassment, insults or personal attacks.
- Keep discussions about MKCinema. Don't ask for or share links to pirated content.
- Help newcomers; everyone started somewhere.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, contact the maintainer through the Security tab's private reporting or the profile at https://github.com/itbelikethatbruh.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).

# mkctv.pages.dev

Short download address for TVs (type `mkctv.pages.dev` into Downloader on a Fire TV).
`/` and `/apk` redirect to `MKCinema-TV.apk`. The APK is not stored here: copy `site/download/MKCinema-TV.apk` into this folder before uploading it to the `mkctv` Cloudflare Pages project. `help.html` is the install help page.

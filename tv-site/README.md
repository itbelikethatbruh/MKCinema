# mkctv.pages.dev

Short download address for TVs (type `mkctv.pages.dev` into Downloader on a Fire TV).
`/` and `/apk` redirect to `MKCinema-TV.apk`. The APK is not stored here: download https://mkcinema.app/download/MKCinema.apk, save it in this folder as `MKCinema-TV.apk` (the phone and TV app are the same file), then upload the folder to the `mkctv` Cloudflare Pages project. `help.html` is the install help page.
